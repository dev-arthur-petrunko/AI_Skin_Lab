## 1. О проекте

**AI Skin Lab** — веб-каталог премиальной косметики и парфумерии с тремя
опорными возможностями:

1. **Автоматическая синхронизация данных** из локального Excel-файла
   (`price.xlsx`) — правка таблицы мгновенно отражается в каталоге без
   перезапуска сервера.
2. **AI-консультант (RAG)** — чат-виджет, который подбирает 1–3 товара под
   описание потребности клиента на основе векторного поиска по каталогу и LLM.
3. **Деплой через Docker + туннелирование** — `docker compose up -d` и
   публикация через Cloudflare Tunnel / Ngrok.

Интерфейс сейчас однолокализованный (`uk`, файл `frontend/src/messages/uk.json`).
Словари `ru` / `en` подключаются добавлением JSON-файла и правкой
`frontend/src/i18n/config.ts` — код к этому готов (см. §5).

| Слой | Технологии |
|---|---|
| Frontend | Next.js 14 (App Router), React 18, Tailwind CSS, Framer Motion, Swiper, three.js (Hero) |
| Backend | Python 3.11, FastAPI, pandas + openpyxl, watchdog, OpenAI SDK, numpy |
| AI | RAG: `text-embedding-3-small` (векторы) + `gpt-4o-mini` (генерация), fallback без ключа |
| Инфра | Docker Compose, Cloudflare Tunnel / Ngrok |
| Качество | `tsc --noEmit`, `next lint` (eslint-config-next), `node check-i18n.js` |

## 2. Дизайн-система

### 2.1. Концепция

Эстетика **premium beauty / niche perfumery**: минимализм, много «воздуха»,
тёплая нейтральная палитра с кофейными акцентами и одним ярким ягодным цветом,
который зарезервирован **исключительно под выгоду и скидки** — взгляд всегда
первым цепляется за цену со скидкой. Типографика — контраст «элегантная
антиква для заголовков + чистый гротеск для интерфейса».

### 2.2. Палитра (токены в `frontend/src/app/globals.css`, классы — в `tailwind.config.ts`)

| Токен | HEX (светлая тема) | Роль | Где применяется |
|---|---|---|---|
| `cream` | `#faf7f2` | фон приложения | `body`, светлые секции |
| `sand` | `#efe7dd` | фон-подложка | изображения товаров, пузыри чата, тени секций |
| `mocha` | `#b08968` | бренд-акцент | надзаголовки, ссылки в hover, фокус-кольца, логотип |
| `espresso` | `#4a3728` | основной текст | заголовки, кнопки, шапка чата |
| `berry` | `#b3235c` | **акцент выгоды** | новая цена, бейдж Sale, % скидки |
| `gold` | `#c9a227` | премиум-акцент | primary-градиент, glow, marquee-разделители |

Тёмная тема переключается атрибутом `[data-theme="dark"]` на `<html>` и
переопределяет те же CSS-переменные (`--bg`, `--ink`, `--sale`, …).

Правило контраста: старая цена — `opacity .45` + зачёркивание (`.price-old`),
новая цена — `--sale` жирным (`.price-new`). Никогда не использовать `berry`
в декоративных целях, иначе акцент выгоды обесценится.

### 2.3. Типографика

| Роль | Шрифт | Токен |
|---|---|---|
| Заголовки, цены-эмоции | **Cormorant Garamond** (антиква) | `font-serif` / `--font-serif` / `--font-disp` |
| Интерфейс, тексты | **Inter** | `font-sans` / `--font-sans` |

Шкала: H1 в `Hero` (`text-4xl → 7xl`), H2 секций `.section-title`
(`text-3xl → 5xl`), надзаголовки `.section-label` (12px, uppercase, трекинг
`0.25em`, цвет `--azure`), тело — 14–16px с `leading-relaxed`.

### 2.4. Сетка и компоненты-примитивы (`globals.css`)

| Класс | Назначение |
|---|---|
| `.container-page` | центрированный контейнер `max-w-8xl` с адаптивными отступами |
| `.glass` / `.tile` | стеклянная панель: градиент + `backdrop-filter: blur(22px)` + блик сверху |
| `.btn` / `.btn-primary` / `.btn-ghost` | кнопки-«пилюли» (`rounded-full`), дл. перехода 300ms |
| `.chip-f` | чип-фильтр (морды в Hero, фильтры каталога, подсказки чата) |
| `.card` | карточка товара: стеклянный фон, `rounded-1.5rem`, мягкая тень |
| `.input` / `.select` | поля ввода/фильтров с кольцом фокуса |
| `.price-old` / `.price-new` | ценовые акценты (см. палитру) |
| `.pearl-edge::before` | анимированная «перламутровая» рамка (градиент `gold → berry → mocha`) |

### 2.5. Анимации

| Эффект | Реализация | Где |
|---|---|---|
| Появление карточек | Framer Motion `whileInView`: `opacity 0→1`, `y 24→0`, каскад `0.06s` | сетки каталога, похожие товары |
| Hover-подъём карточки | Framer Motion `whileHover={{ y: -6 }}` + масштаб картинки `1.05` | `ProductCard` |
| Пульсация Sale | Tailwind `animate-pulse` на ядовито-ярком бейдже | карточки, страница товара |
| Бегущая строка | CSS `@keyframes marquee` 36s linear | `Marquee` под Hero |
| Hero-секция | каскад `stagger`: бейдж → H1 по словам → подзаголовок → кнопки → стата | `Hero` |
| 3D-сцена | three.js: `MeshTransmissionMaterial`, `Float`, `Sparkles`, демпфирование указателя | `HeroScene` / `HeroVisual` |
| Открытие чата | spring (`stiffness 260 / damping 24`), scale+fade | `ChatWidget` |
| Печать ответа | посимвольный вывод по 2 символа каждые 18 мс, курсор `animate-pulse` | `ChatBubble` |
| Счётчики | `CountUp` с easing, запуск при попадании во viewport | Hero-статистика |
| Reduced motion | `@media (prefers-reduced-motion: reduce)` отключает все анимации | `globals.css` |

### 2.6. Структура главной страницы

```
Header (sticky: логотип, 3 ссылки навигации, переключатель темы)
└── main
    ├── Hero        — плиточная сетка (grid-template-areas):
    │                 copy   : H1 (пословная анимация), лид, 2 CTA
    │                 stage  : 3D-стеклянная сцена (fallback — CSS-градиент)
    │                 mood   : «Оберіть категорію» → ссылки на /catalog?q=…
    │                 stats  : товары / бренды / знижки (CountUp)
    ├── Marquee      — бегущая строка УТП (бесплатная доставка, AI-підбір, …)
    └── SaleSection  — горизонтальная Swiper-карусель акционных товаров

```

### 2.7. Страницы

| Роут | Файл | Рендер | Содержимое |
|---|---|---|---|
| `/` | `src/app/page.tsx` | SSR (`force-dynamic`) | Hero + Marquee + SaleSection, топ-10 скидок |

клиенте, чтобы фильтровать мгновенно без сетевого запроса.

## 3. Макеты экранов и расположение окон

Раздел описывает, **что именно видно на экране**, в каком порядке элементы
идут в DOM, чем позиционируются и как ведут себя на разных ширинах.
Файлы-источники: `frontend/src/app/layout.tsx`, `globals.css`,
`frontend/src/components/*`.

### 3.1. Глобальный каркас (одинаков для всех роутов)

```
<html lang="uk" data-theme="light | dark">
└── body  .flex .min-h-screen .flex-col .font-sans
    │
    ├── <Aurora />      position:fixed; inset:0; z:-10    фон-подложка
    ├── <Header />      position:sticky; top:0;  z:40     шапка
    ├── <main .flex-1>                                       контент роута
    ├── <Footer />      margin-top:5rem                    подвал
    └── <ChatWidget />  position:fixed; z:50               плавающее окно
```

`body` — flex-колонка на всю высоту (`min-h-screen`), поэтому `<main
class="flex-1">` растягивается и подвал всегда прижат к низу, даже если
контента мало.

**Карта слоёв (z-index):**

| Слой | Компонент | position | z-index | Примечание |
|---|---|---|---|---|
| Фон | `Aurora` | `fixed inset-0` | `-10` | под всем, клики не ловит |
| Контент | страницы | `static` | `auto` | |
| Шапка | `Header` | `sticky top-0` | `40` | при скролле получает `backdrop-filter` |
| Кнопка чата | `ChatWidget` (trigger) | `fixed bottom-5 right-5` | `50` | поверх футера |
| Панель чата | `ChatWidget` (panel) | `fixed bottom-24 right-4` | `50` | поверх кнопки |
| Бейджи Sale | `ProductCard` / карточка товара | `absolute` | `10` | внутри карточки |
| Перламутровая рамка | `.pearl-edge::before` | `absolute inset-0` | `pointer-events:none` | маска, рисуется поверх |

### 3.2. Фон Aurora

`<Aurora />` — три «пятна» под контентом, всегда на одном месте при скролле:

| # | Размер | Позиция | Цвет | Задержка |
|---|---|---|---|---|
| 1 | `46vw × 46vw` | `left:-10vw; top:-10vw` | `var(--b1)` | `0` |
| 2 | `36vw × 36vw` | `right:-8vw; top:20vh` | `var(--b2)` | `-8s` |
| 3 | `48vw × 48vw` | `left:28vw; bottom:-24vw` | `var(--b3)` | `-14s` |

Все — `border-radius:50%`, `filter: blur(90px)`, `animate-drift` (22 s,
`translate3d(7vw,-6vh)` + `scale(1.18)` на середине цикла), прозрачность
`var(--bo)` (светлая тема `.92`, тёмная `.45`).

### 3.3. Шапка — `Header`

```
 desktop (≥768px)                          mobile (<768px)
┌────────────────────────────────────┐     ┌──────────────────────┐
│ ◯  AI Skin Lab   Головна Каталог   │     │ ◯  AI Skin Lab   🌙  │
│ [logo]             Знижки    🌙    │     │ [logo]                │
└────────────────────────────────────┘     └──────────────────────┘
   лого (left)   nav (center)   тема         лого (left)   тема (right)
```

* Внешний вид: `sticky top-0 z-40`, высота строки `h-16` (64 px),
  внутри `container-page` (`max-w-80rem` + адаптивные поля).
* **До скролла** — прозрачная полоса (`border-b border-transparent`).
* **После `scrollY > 24`** — класс `glass` (матовое стекло
  `backdrop-filter: blur(22px)`), при этом скругление и боковые/верхние
  границы снимаются (`!rounded-none border-x-0 border-t-0`): получается
  сплошная светлая планка во всю ширину.
* **Логотип:** круглая «стеклянная» подложка `h-9 w-9` (36 px) с бликом
  `box-shadow 0 0 12px / inset 0 0 8px`, внутри `next/image` 36×36
  (`/logo.png`) + надпись `font-serif text-xl`.
* **Навигация:** `nav.hidden md:flex gap-7`, три ссылки
  `text-sm font-medium`. Активная (по `pathname`, query отбрасывается) —
  `var(--azure)`, остальные — `var(--muted)`, при наведении → `var(--azure)`.
  Пункты: `/`, `/catalog`, `/catalog?sale=1`.
* **Правая зона:** `ThemeToggle` — кнопка `glass h-10 w-10 rounded-full`
  с эмодзи `🌙` (light) / `☀️` (dark).
* ⚠️ **Ограничение:** на экранах уже 768 px навигация скрыта целиком —
  бургер-меню не реализовано.


**Сетка Hero** (`container-page grid gap-[18px] pt-12 pb-6`):

| Брейкпоинт | Колонки | `grid-template-areas` |
|---|---|---|
| `< 768px` | 1 (поток) | `'copy'` `'stage'` `'mood'` `'stats'` |
| `≥ 768px` (`md`) | `1.2fr 1fr` | `'copy stage'` / `'mood stage'` / `'stats stage'` |

То есть на десктопе блок **stage** растягивается на три строки правой
колонки, а copy/mood/stats складываются в левую.

* **copy** — `h1` `font-serif font-semibold text-4xl md:text-6xl lg:text-7xl`;
  каждое слово — отдельный `motion.span` (`opacity 0→1`, `y 45%→0`,
  `blur(12px)→0`, задержка `0.15 + i·0.09`). Далее лид
  (`max-w-[44ch]`) и две кнопки: `btn-primary` (ссылка `/catalog`) и
  `btn-ghost` **«Запитати AI»**, которая шлёт в окно чата событие
  `ai:open`.
* **stage** — `min-h-[440px] md:min-h-[560px]`, `place-items-center`,
  `overflow-hidden`; внутри `HeroVisual`, который выбирает рендер:
  * WebGL-сцена (`HeroScene`, three.js: 4 стеклянных тела
    `MeshTransmissionMaterial`, `Float`, `Sparkles`, демпфирование
    наклона за указателем) — если есть WebGL2/1, ширина ≥ 768 px,
    `hardwareConcurrency ≥ 4` и не включён `prefers-reduced-motion`;
  * иначе `HeroCssFallback` — три стеклянные плашки 320×320 с 3D-наклоном
    по курсору (`perspective:1000px`, пружины `rotateX/rotateY`),
    плавающие по вертикали ±14 px за 6 с.
* **mood** — заголовок «Оберіть категорію», подпись «Фільтр товарів за
  типом», четыре чипа-ссылки: `Усі → /catalog`,
  `Догляд → /catalog?q=догляд`, `Креми → /catalog?q=крем`,
  `Сироватки → /catalog?q=сироват`.
* **stats** — три блока `Stat`: число `font-serif text-4xl` (`CountUp`,
  стартует при 40 % видимости, easing `1-(1-p)³`, 1.4 с, формат
  `uk-UA`), подпись `text-[13px]`. Третий блок подсвечен цветом скидки
  (`.price-new`).

**Marquee** — `.glass overflow-hidden rounded-full py-3`, строка
`flex w-max gap-10` с пятью пунктами, продублированными ×2 (цикл
бесшовный), разделитель `•` цвета `var(--aqua)`, `animate-marquee` 36 s.

**SaleSection** — `section#catalog-preview.container-page.mt-16`:
шапка `flex justify-between` (слева `section-label` + `section-title`,
справа `btn-ghost` «Дивитись всі знижки» → `/catalog?sale=1`), ниже
`.tile.pearl-edge.is-sale.mt-8` со `Swiper`-каруселью:

| Параметр | Значение |
|---|---|
| `spaceBetween` | 24 px |
| `slidesPerView` | `1.15` → `2.2` (640) → `3.4` (1024) → `4.4` (1280) |
| `loop` | только если товаров > 4 |
| `autoplay` | 4500 ms, пауза при наведении, не отключается после клика |
| `pagination` | точки внизу, активная `var(--azure)` |
| Пустой список | строка «Наразі акційних пропозицій немає» |

### 3.5. Каталог — `/catalog`

```
┌─ Header ───────────────────────────────────────────────────┐
│ КАТАЛОГ ТОВАРІВ                                            │
│ Зручні фільтри допоможуть знайти саме те, що шукаєте        │
│ ┌─ .tile ────────────────────────────────────────────────┐ │
│ │ [🔍 Пошук за назвою…] [Бренд ▾] [Категорія ▾]         │ │
│ │ [Сортування ▾]  [Тільки зі знижкою] [✕]                │ │
│ └────────────────────────────────────────────────────────┘ │
│ 24 товарів                          07.10.2026, 17:11:22   │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐     │
│ │ card   │ │ card   │ │ card   │ │ card   │ │ card   │     │
│ └────────┘ └────────┘ └────────┘ └────────┘ └────────┘     │
│              …                       [Показати ще]         │
└─ Footer ───────────────────────────────────────────────────┘
```

* Заголовок: `section-label` (КАТАЛОГ ТОВАРІВ) + `h1.section-title`.
* Панель фильтров — `.tile mt-8 p-4 sm:p-5`, внутренняя сетка
  `grid gap-3 lg:grid-cols-[1fr_auto_auto_auto_auto]`: на десктопе всё в
  одну строку (поиск тянется), на мобильном — в столбик.
  1. `input.input` — поиск; инициализируется из `?q=`
     (так работают ссылки чипов из Hero);
  2. `select.select` «Бренд» — значения из `initial.brands`;
  3. `select.select` «Категорія» — значения из `initial.categories`;
  4. `select.select` «Сортування» — `за замовчуванням / ціна ↑ / ціна ↓ /
     вигідність знижки / за назвою`;
  5. `div.flex.gap-2`: чип **«Тільки зі знижкою»** (`aria-pressed`) и
     чип **✕** со сбросом — появляется только когда есть хотя бы один
     активный фильтр, подписан `aria-label="Скинути фільтри"`.
* Строка итогов: слева `«{n} товарів»`, справа дата `last_updated`
  (`toLocaleString("uk-UA")`).
* Сетка карточек: `grid gap-4` → `grid-cols-2` / `sm:3` / `lg:4` / `xl:5`.
* Пагинация — «нарастание»: `PAGE_SIZE = 12`, кнопка `btn-ghost`
  «Показати ще», сбрасывается при любом изменении фильтра.
* Пустой результат — одна строка
  «Нічого не знайдено. Спробуйте змінити фільтри.»
* Фильтрация выполняется **на клиенте** (`useMemo` по `items`), поэтому
  мгновенно; канонические query-параметры (`search`, `brand`, `category`,
  `on_sale`, `sort`) умеет и backend.

**Карточка товара (`ProductCard`)** — общий элемент каталога, главной и
блоков «похожие»:

```
┌─ .tile.pearl-edge (.is-sale) ─┐
│ [SALE]              (abs 3/3) │   обложка aspect-[4/5]
│ ┌───────────────────────────┐ │   img object-cover
│ │        картинка           │ │   hover → scale 1.05
│ │ ─────────────────────── │ │   снизу выезжает
│ │      «Детальніше»         │ │   подложка black/70
│ └───────────────────────────┘ │
│ БРЕНД                (11px)   │   цвет var(--azure)
│ Назва товару (2 строки)       │   line-clamp-2
│ 1100 грн   1400 грн   [-21%]  │   price-new / price-old
└───────────────────────────────┘
```

Вход — `whileInView opacity 0→1, y 24→0` со сдвигом `index·0.06s`
(максимум 0.4 s), при наведении подъём `y: -6`, плюс «параллакс»
подсветки через CSS-переменные `--gx/--gy`, вычисляемые от позиции
курсора.

### 3.7. Окно AI-чата — `ChatWidget`

Единственное «всплывающее окно» приложения. Состоит из двух независимо
позиционированных элементов.

```
                                 ┌──────────────────────────┐
                                 │ ✨  AI-консультант     ✕ │  шапка px-5 py-4
                                 │    Експерт з парфумерії   │  ● зелёная точка
                                 ├──────────────────────────┤
                                 │      ┌──────────────┐    │
                                 │      │ Вітаю! 👋 …   │    │  ассистент (слева,
                                 │      └──────────────┘    │  .glass)
   …                             │  ┌───────────────────┐   │
                                 │  │ підбірка крему…   │   │  пользователь (справа,
                                 │  └───────────────────┘   │  var(--azure))
                                 ├──────────────────────────┤
                                 │ [Мені потрібен легкий…]  │  подсказки (chip-f)
                                 ├──────────────────────────┤
                                 │ [Опишіть вашу потребу] ↑ │  форма
                                 └──────────────────────────┘
              ┌─────────────────────────┐
              │  ✨ AI-консультант      │  кнопка-триггер
              └─────────────────────────┘
                        right-5 / bottom-5
```

**Кнопка-триггер**
`fixed bottom-5 right-5 z-50`, `h-14`, `rounded-full`, `btn btn-primary
!px-5`. Внутри: `span h-6 w-6` с эмодзи ✨ и пульсирующей точкой
`var(--sale)` в правом верхнем углу; подпись «AI-консультант» —
`hidden sm:inline` (появляется с 640 px). Появление — spring
(`delay 1s, stiffness 200, damping 16`), при наведении `scale 1.06`,
при нажатии `0.95`. Атрибут `aria-label` = «AI-консультант».

**Панель диалога**
`fixed bottom-24 right-4 z-50`, размеры
`w-[calc(100vw-2rem)] max-w-md` × `h-[70vh] max-h-[640px]`, стеклянная
плитка `.tile !rounded-3xl !p-0`. Открытие/закрытие — spring
(`stiffness 260, damping 24`), уходит вниз с `opacity/scale 0.96`.

| Часть | Вёрстка |
|---|---|
| Шапка | `flex gap-3 px-5 py-4`: круглая иконка `h-9 w-9` (✨) → колонка «заголовок + подзаголовок с зелёной точкой `h-1.5 w-1.5 bg-green-400`» → кнопка `✕` (`p-1.5`, hover `var(--pic)`) |
| Лента | `div.chat-scroll flex-1 space-y-4 overflow-y-auto p-4`; скроллбар 6 px, бегунок `var(--pic)` |
| Сообщения | пользователь — `justify-end`, пузырь `max-w-[85%] rounded-2xl rounded-tr-sm bg-[var(--azure)] text-white`; ассистент — `justify-left`, компонент `ChatBubble` на `.glass` |
| «Печатает» | три точки `.typing-dot` (blinkdot 1.4 s, задержки 0.2/0.4 s) + «Підбираю для вас ідеальні варіанти…» |
| Карточки в ответе | до 3 штук: превью 48×48 + бренд + название (truncate) + цена, ссылка на `/product/[id]` |
| Подсказки | показываются только пока `messages.length ≤ 1`: три `chip-f !text-xs` |
| Форма | `flex gap-2 p-3`: `input.input.flex-1` + кнопка `btn-primary !h-10 !w-10` со стрелкой `↑` (`disabled`, если пусто или идёт запрос) |
| Печать текста | 2 символа каждые 18 мс, курсор `animate-pulse`; при `prefers-reduced-motion` анимации отключены |

**Триггеры открытия:**

| Источник | Что происходит |
|---|---|
| Клик по кнопке | toggle панели |
| Событие `ai:open` без `detail` | открыть панель |
| Событие `ai:open` c `detail.message` | открыть панель **и** вставить текст в поле ввода (Hero «Запитати AI», кнопка «Порадитись з AI» на странице товара) |

Состояния ошибки/офлайна: если `OPENAI_API_KEY` не задан или запрос
упал, приходит `FALLBACK_REPLY` на языке запроса + карточки товаров,
поэтому окно никогда не показывает «сырую» ошибку.

### 3.10. Брейкпоинты и поведение сеток

| Имя | Ширина | Что меняется |
|---|---|---|
| базовый | `< 640` | 1 колонка почти везде; в Marquee/чате подписи скрыты |
| `sm` | `≥ 640` | Swiper 2.2 слайда; сетка каталога 3 колонки; футер 2 колонки; подписи `hidden sm:inline` в кнопке чата |
| `md` | `≥ 768` | шапка получает навигацию; Hero переключается на 2 колонки (`1.2fr 1fr`); включается WebGL-сцена |
| `lg` | `≥ 1024` | Swiper 3.4; сетка каталога 4 колонки; футер 3 колонки; панель фильтров в одну строку; страница товара 2 колонки |
| `xl` | `≥ 1280` | Swiper 4.4; сетка каталога 5 колонок; контейнер упирается в `max-w 80rem` |

Поля контейнера (`.container-page`): `1rem` → `1.5rem` (sm) → `2rem` (lg).

Вертикальные ритмы: Hero `pt-12 pb-6` · Marquee сразу за ним ·
SaleSection `mt-16` · каталог `py-14` · товар `py-12` ·
секция «похожие» `mt-20` · футер `mt-20`, внутренние `py-14` / `py-5`.

### 3.11. Радиусы, фокус и доступность

| Элемент | Скругление |
|---|---|
| `.glass`, `.tile`, `.card` | `var(--r) = 24px` (`.card` — 1.5rem) |
| `.btn`, `.chip-f`, `.input`, `.select` | `9999px` (полная «пилюля») |
| Панель чата | `!rounded-3xl` |
| Пузыри сообщений | `rounded-2xl`, у пользователя верхний правый угол срезан (`rounded-tr-sm`) |
| Бейджи Sale, аватарки, кнопка чата | полный круг |

* Фокус — глобально: `:focus-visible { outline: 2px solid var(--aqua);
  outline-offset: 3px; }`.
* `prefers-reduced-motion: reduce` — отключает **все** анимации и переходы
  (включая marquee, stagger и печать в чате) и заставляет `HeroVisual`
  выбрать CSS-fallback вместо WebGL.
* Изображения — нативный `<img loading="lazy">` с `onError` →
  `/images/placeholder.svg`, чтобы битая ссылка не оставляла дыру.

### 3.12. Известные ограничения вёрстки

1. **Нет мобильного меню** — ниже 768 px навигация из шапки исчезает
   целиком (бургер не реализован), доступны только логотип и переключатель
   темы.
2. **Нет модальных окон и корзины** — покупка смоделирована: «Купити»
   открывает AI-чат.
3. **Нет `error.tsx` / `not-found.tsx`** — используется стандартная 404
   страница Next.js.
4. **Нет страницы «О нас»** — пункт `Про нас` есть в словаре (`nav.about`),
   но в шапку не выведен.
5. **Карточка 404** — `notFound()` вызывается только на `/product/[id]`;
   неизвестный роут рендерит built-in `/_not-found`.

## 4. Backend

### 4.1. Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/catalog` | список + фильтры + `brands` / `categories` / `last_updated` |
| `GET` | `/api/catalog/sale` | акционные товары, сортировка по % скидки (`limit`) |
| `GET` | `/api/catalog/{id}` | один товар, `404` если нет |
| `POST` | `/api/chat` | RAG-чат: `{message, lang, history[]}` → `{reply, products[]}` |
| `GET` | `/api/health` | `{status, products, last_updated}` — healthcheck в compose |
| `GET` | `/admin/reload` | принудительная перезагрузка каталога |
| `GET` | `/admin/translate` | `?to=ru,en&dry_run=&sku=` — заполняет пустые ru/en-ячейки в Excel |
| `GET` | `/images/*` | статика из `data/images/` |

**Безопасность `/admin/*`:** оба эндпоинта требуют заголовок
`X-Admin-Token`, значение которого задаётся в `.env` (`ADMIN_TOKEN=`).
Если токен не задан — эндпоинты возвращают `404` и полностью выключены,
поэтому деплой по умолчанию не открывает запись в Excel извне.

### 4.2. Синхронизация каталога

`backend/app/store.py` держит каталог в памяти под `RLock` и запускает
два наблюдателя:

1. `watchdog.Observer` на каталог `data/` (дебаунс 1 с);
2. поток опроса `mtime` каждые 3 с — страховка для Docker Desktop на Windows,
   где inotify не прокидывается в контейнер.

Каталог перечитывается автоматически, `on_reload`-колбэк пересобирает
векторный индекс AI. Проверка: `GET /api/health` → поле `last_updated`.

### 4.3. Разбор Excel

`backend/app/catalog_loader.py`:
* таблица псевдонимов колонок (`Артикул`/`SKU`/`ID`, `Ціна, грн`/`Price`, …);
* нормализация чисел/текста, расчёт скидки, если `%` не заполнен;
* категория — из колонки `Категорія`, иначе по ключевым словам
  (`CATEGORY_KEYWORDS`), иначе «Інше»;
* теги (`_extract_tags`) — для поиска и промпта AI;
* изображение — колонка `Фото` (код без расширения дополняется
  `.jpg/.png/.webp`), затем `<Артикул>`, затем `<Артикул>` с ведущими нулями
  (`2 → 002.png`), иначе `placeholder.svg`;
* дубликаты артикулов получают суффикс (`2-2`, `2-3`), а не теряются.

### 4.4. AI-консультант (RAG)

1. При загрузке каталога `VectorIndex.build()` эмбеддит «название + бренд +
   категория + описание + теги» через `text-embedding-3-small`.
2. Запит → cosine similarity (NumPy, top-5) → системный промпт с товарами →
   `gpt-4o-mini` (`temperature 0.6`, `max_tokens 500`) → текст + ≤3 карточки.
3. Без `OPENAI_API_KEY` (или при ошибке API) — keyword-поиск и заготовленный
   ответ на языке запроса: функциональность не падает, карточки товаров
   всё равно подбираются.

## 5. Конфигурация

`backend/app/config.py` — `pydantic-settings`, читает `.env` **из корня
проекта** (и, как запасной вариант, из рабочей директории), все неизвестные
ключи игнорируются.

| Переменная | Назначение | По умолчанию |
|---|---|---|

| `IMAGES_DIR` | каталог изображений | `<корень>/data/images` |
| `OPENAI_API_KEY` | ключ OpenAI (пусто = fallback-режим) | `""` |
| `OPENAI_BASE_URL` | базовый URL API | `https://api.openai.com/v1` |
| `CHAT_MODEL` / `EMBEDDING_MODEL` | модели | `gpt-4o-mini` / `text-embedding-3-small` |
| `ALLOWED_ORIGINS` | CORS, через запятую | `http://localhost:3000,http://localhost:8000` |
| `AUTO_TRANSLATE` | авто-перевод ru/en при перезагрузке каталога | `0` |
| `ADMIN_TOKEN` | ключ `/admin/*` (пусто = эндпоинты выключены) | `""` |
| `SHEET_NAME` | лист Excel | `Зручна таблиця` |
| `CURRENCY` | единица цены в UI/AI-промпте | `грн` |

`docker-compose.yml` задаёт контейнерные пути сам (`/app/data/...`),
поэтому `.env` можно не дополнять для Docker-запуска.
